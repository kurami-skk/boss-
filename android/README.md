# 🛡️ 求职防骗助手 - Android App

> 一款运行在安卓手机上的 Boss直聘 岗位分析工具
> 
> 支持：📸 拍照识别 · 🖼️ 相册导入 · 📝 粘贴文本

---

## 📥 如何获取 APK（超简单，3步搞定）

### 第 1 步：上传到 GitHub

1. 打开浏览器，登录你的 [GitHub](https://github.com) 账号
2. 点击右上角 `+` → **「New repository」**（新建仓库）
3. 仓库名称填写：`JobGuardApp`
4. 选择 **「Public」**（公开）
5. 点击 **「Create repository」**
6. 在新页面中，点击 **「uploading an existing file」**（上传已有文件）
7. 打开本电脑的 `android` 文件夹，**全选所有文件** 拖拽到网页上
8. 往下滚动，点击 **「Commit changes」**（提交）

> ⏳ 上传后，GitHub 会自动开始构建 APK，约 5-10 分钟完成

### 第 2 步：下载 APK

1. 在 GitHub 仓库页面，点击顶部 **「Actions」** 标签
2. 你会看到一个叫 **「构建 APK」** 的工作流正在运行（黄色圆点表示进行中）
3. 等待它变成 ✅ 绿色勾
4. 点击这个工作流，往下滚动到 **「Artifacts」**（构建产物）
5. 点击 **「求职防骗助手-Debug」** 下载 APK 压缩包

### 第 3 步：安装到手机

1. 将下载的 `求职防骗助手-Debug.zip` 解压，得到 `.apk` 文件
2. 用数据线传到手机，或用微信/QQ发送到手机
3. 在手机上点击 `.apk` 文件安装
4. 如果提示「未知来源应用」，点击 **「设置」→「允许安装」**
5. 安装完成后，桌面上就会出现 **🛡️ 求职防骗助手** 的图标！

## 📱 如何使用

### 🖼️ 从相册分析
1. 打开 App，点击 **「从相册选择截图」**
2. 选择一张 Boss直聘 的岗位截图
3. App 会自动识别图中的文字并分析
4. 等待几秒，查看分析报告

### 📸 拍照分析
1. 点击 **「拍照识别」**
2. 对准电脑或手机上的招聘信息拍照
3. App 会自动识别照片中的文字并分析

### 📝 粘贴文本分析
1. 在 Boss直聘 App 中复制岗位介绍
2. 打开本 App，粘贴到文本框中
3. 点击 **「开始分析」**

## 📊 分析报告说明

| 模块 | 说明 |
|------|------|
| **安全评分** | 0-100 分，从可信度、透明度、合理性三维度评分 |
| **欺诈检测** | 检测 11 类常见招聘欺诈特征，标注风险等级 |
| **岗位解读** | 分析薪资、要求、福利、公司信息、职业发展 |
| **求职建议** | 根据分析结果提供个性化的行动建议 |

## ⚠️ 重要提示

- 🔒 **所有数据仅在手机本地分析**，不会上传到任何服务器
- 📋 分析结果仅供参考，不构成专业法律意见
- 🚨 如遇可疑招聘，请及时向 Boss直聘 平台举报或拨打 110
- 💡 建议结合「企查查」「天眼查」核实公司信息
