# 🛡️ 求职防骗助手 - Boss直聘岗位分析工具

> 智能分析Boss直聘招聘信息，识别欺诈职位，解读岗位内容，保护求职者权益

## 📱 功能特点

- **🔍 欺诈检测**：自动检测 11 类常见招聘欺诈特征
  - 高薪低门槛陷阱
  - 要求先交费
  - 传销/拉人头
  - 培训贷骗局
  - 境外高薪骗局
  - 以及其他欺诈模式
- **📊 安全评分**：从可信度、透明度、合理性三维度综合评分
- **📋 岗位解读**：自动分析薪资、要求、福利、公司信息、职业发展
- **💡 求职建议**：根据分析结果提供个性化求职建议
- **🌙 深色模式**：支持深色/浅色主题切换
- **📤 分享功能**：一键分享分析报告
- **📱 PWA 支持**：可安装到手机桌面，像原生App一样使用

## 🚀 使用方法（超简单！）

### 方法一：直接用浏览器打开（推荐）

1. 打开文件夹，双击 `index.html` 文件
2. 在浏览器中即可使用全部功能
3. 可以添加到手机桌面：

   **Android Chrome 浏览器：**
   - 打开 `index.html`
   - 点击浏览器菜单（右上角三个点）
   - 选择「添加到主屏幕」
   - 点击「添加」

### 方法二：生成图标后安装到手机

> 图标不是必须的，但可以让App看起来更专业

1. 双击打开 `icon-generator.html`
2. 点击「📦 下载全部尺寸图标」
3. 将下载的 `icon-*.png` 文件全部移动到 `icons/` 文件夹中
4. 刷新 `index.html`，然后添加到手机桌面

### 方法三：使用在线工具（最简单）

如果你不想下载文件，可以直接把 `index.html` 的内容保存到手机，用浏览器打开即可。

## 📖 使用步骤

### 第一步：获取岗位信息

在 Boss直聘 App 中：

- **方式A（链接）**：打开岗位详情 → 点击分享 → 复制链接
- **方式B（内容）**：长按岗位介绍 → 全选 → 复制

### 第二步：粘贴到工具

- 打开本工具
- 选择「粘贴链接」或「粘贴内容」模式
- 将复制的内容粘贴到输入框
- 也可以点击「试试示例数据」体验功能

### 第三步：开始分析

- 点击「开始分析」按钮
- 等待约 3-5 秒
- 自动生成分析报告

### 第四步：查看报告

报告包含：
1. **安全评分** - 综合安全评分（0-100分）
2. **欺诈检测** - 列出所有检测到的风险特征
3. **岗位解读** - 对薪资、要求、福利等的详细分析
4. **求职建议** - 个性化的行动建议
